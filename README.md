# commerce-pos-releases

Commerce POS installers and updates for Windows. The source code is private; this repository only hosts the releases.

## Descargar el punto de venta

**[Página de descarga](https://incoders-tools.github.io/commerce-pos-releases/)**: el instalador más reciente de producción y de pruebas, con los pasos para instalarlo.

Las cajas ya instaladas se actualizan solas. Para una caja nueva, o para actualizar una que no se actualiza sola,
bajá el instalador desde la página, descomprimilo y ejecutá "Instalar Commerce POS.cmd". **No desinstales la versión
anterior**: el instalador actualiza encima y conserva los datos de la caja.

All releases: [Releases](https://github.com/Incoders-Tools/commerce-pos-releases/releases).
